# DocuMind

AI-Powered PDF Summarization and Content Generation

## ✨ Features

- 📄 Upload PDF documents
- 🤖 AI-generated summaries
- 🧠 Automatic quiz generation
- 📑 AI-generated presentation slides from documents

## 🛠 Tech Stack

### Frontend
- React.js
- Material UI
- Axios
- React Router

### Backend
- FastAPI
- Python
- PyPDF2

### AI Integration
- OpenAI API
